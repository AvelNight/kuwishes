# kuwishes

Доска желаний: картинки из архива, статусы правятся в коде — без авторизации.

## Локально

```bash
cd /path/to/kuwishes
python3 -m http.server 8080
```

Открыть http://localhost:8080

## На reg.ru

1. Залить содержимое папки в `public_html` (или поддомен) через FTP / файловый менеджер.
2. PHP не нужен — хватит обычного статического хостинга.
3. Чтобы сменить статус желания: отредактировать `js/wishes.js` и залить файл снова.

```js
status: "dream"   // мечта
status: "active"  // в фокусе (подсветка + анимация)
status: "done"    // сбылось
```

Можно править `title` и `note`. Новые картинки — в `images/`, плюс запись в `WISHES`.
